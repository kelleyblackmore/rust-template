# rust-template

[![CI](https://github.com/kelleyblackmore/rust-template/actions/workflows/ci.yml/badge.svg)](https://github.com/kelleyblackmore/rust-template/actions/workflows/ci.yml)

A template repository for Rust projects.

## Features

- Modern Rust (2021 edition)
- CI/CD with GitHub Actions
- Clippy linting with pedantic checks
- Automated testing
- Documentation generation

## Usage

Use this template to create a new repository, then customize it for your needs.

### Building

```bash
cargo build
```

### Testing

```bash
cargo test
```

### Linting

```bash
cargo clippy
```

### Documentation

```bash
cargo doc --open
```
